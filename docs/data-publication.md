## 公开公示的依据与选择

[北京市科委 2026 年第一批拟入库公示](https://kw.beijing.gov.cn/zwgk/tzgg/202607/t20260709_4754163.html)提供拟入库名单和附件，但本次核对的通知页面没有给出明确的批量再分发许可。这个观察不等于认定禁止使用；首版选择发布来源索引和无企业名汇总，待核实适用条款后再决定是否附名册。名单出现不等于最终入库，也不等于企业授权。

## 克隆后的运行和复现

公开包可运行模拟预审、证据图、规则变化预览与合成困难集测试。评测中心优先读取本机逐条结果；没有逐条结果时显示随仓库分发的**历史汇总**，不会把它标为本次重跑。

如需在本机重跑公开资料评测，先按来源页面及适用条款获取资料，准备 `data/public_candidate_seed_2026.json` 和 `data/public_case_records_2026.jsonl`。结构生成脚本为 `scripts/build_public_case_records.py`；不得用编造企业代替历史 50 条记录。上述本地文件及生成的带名结果仍由 `.gitignore` 排除。运行 `scripts/sanitize_public_summary.py` 可重新导出仅含计数的汇总；其日期沿用实际评测结果，不是生成汇总的日期。

运行 `scripts/build_public_release.py` 会扫描公开候选文件，再生成独立源码 ZIP 和逐文件 SHA-256 清单。忽略规则不会保护已经进入 Git 的文件，因此扫描也检查已跟踪文件与嵌套 ZIP。任何需要分发新的真实资料、Office 文档或模型文件的变更，须先调整范围并重新审核，不能仅删除忽略规则。
