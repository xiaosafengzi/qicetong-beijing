# 企策通公开数据评测路线

## 50 条公开记录与历史评测

**源码发布范围（2026-10-08）：** 仓库提供 `artifacts/public-notice-summary.json` 历史汇总与来源链接。逐条名册、带名结果和采集台账保留在开发者本机，重跑评测需准备原始记录，见 `docs/data-publication.md`。

`data/public_case_records_2026.jsonl` 从 [北京市 2026 年第一批拟入库科技型中小企业公示](https://kw.beijing.gov.cn/zwgk/tzgg/202607/t20260709_4754163.html)及其附件提取 50 条记录，覆盖 16 个区。字段包括公示序号、企业名称、注册区、发布日期和来源链接，标签为“出现在这批**拟入库公示**中”。最终入库结果、人员、研发投入、收入、知识产权证据和申报材料均记为未观察到。数据类型为公开公示记录，当前授权企业案例为 0。

这 50 条记录可用于测试公示 PDF 抽取、来源引用、拟入库状态识别，以及缺少申报材料时的未知状态处理。

`scripts/evaluate_public_notice.py` 的历史结果为：50/50 返回待补证/复核，误判为“已核对通过”的记录为 0 条。逐条结果保存在本机 `artifacts/public-notice-results.json`，公开汇总保存在 `artifacts/public-notice-summary.json`。评测指标衡量申报材料缺失时的拒判行为；资格准确率需使用完整申报材料另行测量。

北京市公共数据开放平台的[法律声明](https://data.beijing.gov.cn/gywm/mzsm/index.htm)说明，平台提供的政务数据可免费获取并非排他使用，利用和分享时应注明“北京市公共数据开放平台”来源，并按平台要求备案；下载或调用 API 通常需要注册。每个数据集的开放条件仍需在其详情页核对。政府公示页面与平台数据集应分别保留原始链接、发布日期、抓取时间和具体使用范围。

## 推荐的评测分层

1. **公开资料层**：使用 50 条公示记录及可获取的开放数据，测量检索、抽取、跨来源匹配、证据引用和未知状态处理。
2. **合成材料层**：使用合成的多文档材料，测量人员、财务、研发投入、知识产权和冲突推理。
3. **授权企业层**：取得明确授权后，进行脱敏和业务人员独立标注，测量真实案例效果。结构校验参考 `data/authorized_case_schema.json` 与 `scripts/validate_authorized_case.py`，授权真实性由人工核验。

三层评测分别报告数量、来源和指标。
