# 企策通公开数据评测路线

## 已可直接使用的 50 条公开记录

**源码发布范围（2026-10-08）：** 以下逐条数据仅保留在开发者本机，首版 GitHub 源码包不附企业名册、带名结果或采集台账，只附 `artifacts/public-notice-summary.json` 历史汇总与来源链接。汇总不能代替原数据重新评测；详细范围见 `docs/data-publication.md`。

`data/public_case_records_2026.jsonl` 从 [北京市 2026 年第一批拟入库科技型中小企业公示](https://kw.beijing.gov.cn/zwgk/tzgg/202607/t20260709_4754163.html)及其附件提取 50 条记录，覆盖 16 个区。每条只保留公示序号、企业名称、注册区、发布日期和来源链接。唯一可直接验证的标签是“出现在这批**拟入库公示**中”；最终入库结果、人员、研发投入、收入、知识产权证据和申报材料都标为未观察到。它们不是“获得企业授权的脱敏案例”。

这 50 条可用于测试公示 PDF 抽取、来源引用、拟入库与正式入库状态区别，以及材料不足时输出“未知”而非编造结论。不能据此计算完整的科技型中小企业或高企申报通过率。

已运行 `scripts/evaluate_public_notice.py`。50 条记录在不补造人员、财务和知识产权事实的前提下均返回待补证/复核，错误宣称“已核对通过”为 0 条；覆盖 16 个区。结果保存在 `artifacts/public-notice-results.json`。这个结果只验证资料不足时的拒判行为，不能解释为资格判定准确率，也不能把公示出现视为最终入库或获得授权。

北京市公共数据开放平台的[法律声明](https://data.beijing.gov.cn/gywm/mzsm/index.htm)说明，平台提供的政务数据可免费获取并非排他使用，利用和分享时应注明“北京市公共数据开放平台”来源，并按平台要求备案；下载或调用 API 通常需要注册。每个数据集的开放条件仍需在其详情页核对。政府公示页面与平台数据集应分别保留原始链接、发布日期、抓取时间和具体使用范围。

## 推荐的评测分层

1. **公开资料层**：用 50 条公示记录及可获取的开放数据测检索、抽取、跨来源匹配、证据引用和“未知”处理。报告结果只称“公开资料评测”。
2. **合成材料层**：用明确标注为合成的多文档材料测人员、财务、研发投入、知识产权和冲突推理。不得称为真实企业成绩。
3. **授权企业层**：未来取得明确授权后，进行脱敏和业务人员独立标注，再报告真实案例评测结果。结构校验参考 `data/authorized_case_schema.json` 与 `scripts/validate_authorized_case.py`；格式合格不代表已取得授权。

评测报告应分别给出这三层的数量、来源和指标，不把公开名单或合成材料并入“已授权真实案例”。
