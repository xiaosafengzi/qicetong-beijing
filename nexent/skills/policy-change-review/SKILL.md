# 政策变更复核

通过 `list_policy_catalog` 确认两个版本属于同一事项。当前可比较 `sme-bj-2025` 与 `sme-bj-2026`。

调用 `compare_policy_versions(old_policy_id, new_policy_id, as_of)`。将年度、受理日期、材料期间的变化与实质门槛变化分开描述。工具未返回门槛变化时，不声称门槛提高或降低。

按 impacts 列出受影响企业和 review_rule_ids。用户要求进一步核查时，逐家调用 `review_enterprise` 使用新版本执行，并保留人工核查事项。

说明比较使用的核查日期，不把两年前的已截止通知解释为今天仍可申报。当前不会自动发布上传文件中抽取的候选规则；新文件只形成待核对证据或概念候选。

如用户已在企策通工作台上传新政策材料，可调用 `preview_uploaded_policy_change(asset_id, policy_id, as_of)` 对齐明确写出的数值上限，并查看逐家企业的假设影响。候选来自上传文件，必须核验发布机关、正式原文、适用地区、有效期及条款上下文。不得把预览值称为已生效规则，也不得据此覆盖政策库。

输出变更清单、两份原文链接、需要更新的资料、企业复核结果；标明模拟企业。不得修改或删除历史预审报告。
