# 系统效果评测

调用 `get_system_evaluation` 读取已经运行并保存的评测结果。只报告工具返回的案例数、状态准确率、缺失字段准确率、分类结果和耗时，不根据演示观感推算指标。

说明对比口径：两种方法接收同一政策规则和同一组结构化企业事实；确定性引擎执行单位、期间、证据状态和规则计算，单模型基线直接判断单项规则。评测集由公开政策规则和模拟企业数据构造，不包含真实企业结论。

报告失败案例时保留案例 ID、预期状态和预测状态。评测结果缺少 `llm_baseline` 时，只能说明尚未运行单模型消融，不得填造对比数值。

结论必须附带边界：当前指标证明工程规则在随仓库提供的困难案例上的可复现性，不能外推为现实申报通过率或所有政策场景的准确率。
